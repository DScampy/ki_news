Anthropic startet Claude Ship mit automatischer Code-Genehmigung

Die neue Suite bündelt Code Review mit den Beta-Agenten PR Steward und Claude Approvals, die routinemäßige Änderungen automatisch freigeben können.

Anthropic hat Claude Ship vorgestellt, eine Suite von KI-Agenten, die Code-Reviews, Fehlerbehebungen und Genehmigungen automatisieren soll. Das Angebot besteht aus drei Teilen: Code Review, das bereits allgemein verfügbar ist, sowie den beiden neuen Agenten PR Steward und Claude Approvals, die sich in der Beta-Phase befinden. Claude Ship ist für Claude Team- und Enterprise-Kunden verfügbar und funktioniert mit Repositories auf GitHub. Der interessanteste Teil ist die automatische Genehmigung von Code-Änderungen durch einen Agenten, basierend auf Richtlinien, die das Entwicklungsteam festlegt.[1][2][4]

PR Steward kümmert sich um fehlgeschlagene CI-Checks, Merge-Konflikte und Feedback aus dem Code Review. Nach jedem Push hinterlässt er Kommentare dazu, was geändert wurde und wie man die Änderungen bei Bedarf rückgängig machen kann. Claude Approvals übernimmt dann die Anwendung einer Genehmigungsrichtlinie, die als Datei im Repository hinterlegt wird. Diese Richtlinie kann verschiedene Signale berücksichtigen, darunter die Ergebnisse des Code Reviews oder eigene Klassifikatoren des Unternehmens. Die Richtlinien werden in natürlicher Sprache verfasst.[1][2][4]

Anthropic weist darauf hin, dass Teams die Kontrolle behalten: Sie entscheiden, wo Claude Ship läuft, welche Review-Einstellungen verwendet werden (Quick, Standard oder Deep) und welche Änderungen zur menschlichen Entscheidung eskaliert werden. Da sich die Genehmigungsfunktion noch in der Beta befindet, empfiehlt das Unternehmen, sie zunächst im Beobachtungsmodus zu betreiben. Teams können auch mit nur einem Repository starten und monatliche Ausgabenlimits festlegen, um den Prozess besser zu kontrollieren.[1][4]

Die Einführung von Claude Ship zielt auf einen Engpass, der durch die zunehmende Nutzung von KI-Codegenerierung entstanden ist: Während KI-Agenten immer mehr Code schreiben, bleibt die Überprüfung und Genehmigung von Änderungen oft an Menschen hängen. Anthropic argumentiert in einem Blogbeitrag, dass viele Entwickler inzwischen mit Agenten arbeiten und der Prozess nach dem Pull-Request genauso schnell sein soll. Auf dem eigenen Claude-Code-Team schreibe Claude den Großteil des Codes, so das Unternehmen.[1][4]

Ob die automatische Genehmigung durch einen KI-Agenten in der Praxis zuverlässig funktioniert, ist noch offen. Die Beta-Phase und die Empfehlung, zunächst nur zuzusehen und Limits zu setzen, deuten auf Vorsicht seitens Anthropic hin. Für Entwicklungsteams bedeutet das neue Werkzeug eine Verschiebung: Sie legen die Regeln fest, nach denen Code freigegeben wird, und delegieren die Entscheidung im Einzelfall an die KI. Wie sich das auf die Qualität und Sicherheit des Codes auswirkt, werden die ersten Nutzer zeigen müssen.[1][4]
