Manipulierte Claude-Code-Erweiterung im Cursor-Marktplatz betraf höchstens 5.000 Nutzer

Eine Version 2.1.313 der Claude-Code-Erweiterung enthielt im Cursor-Marktplatz eine SSH-Hintertür. Laut Cursor waren höchstens 5.000 Nutzer betroffen. Wie die Angreifer ins Konto kamen, ist unklar.

Im Marktplatz der Entwicklungsumgebung Cursor war eine manipulierte Version der Erweiterung Claude Code for VS Code verfügbar. Laut Cursor betraf der Vorfall höchstens 5.000 Nutzer. Die Version 2.1.313 enthielt eine SSH-Backdoor mit Routinen für Linux, macOS und Windows. Cursor nennt manipulierte Pakete für macOS und Windows.[3][5]

Die Angaben zur Dauer weichen ab. Heise nennt unter Berufung auf Cursor die Zeit zwischen 10:27 und 21:35 Uhr mitteleuropäischer Zeit am Donnerstag, das wären gut elf Stunden. The Decoder spricht von rund elf Stunden. Ars Technica schreibt dagegen von fast 12 Stunden. Auch zur Herkunft gibt es Differenzen im Detail: Anthropic stellte laut dem Forscher Kevin Beaumont einige Stunden später Version 2.1.314 bereit.[1][2][3]

Ob Anthropic die Version gebaut hat, wird unterschiedlich dargestellt. Cursor sagt, der manipulierte Build stamme nicht von Anthropic. Laut Beaumont und Luke Roberts (CTO und Mitgründer Phorian) wurde 2.1.313 jedoch über Anthropics offiziellen Account auf Cursor verteilt. Roberts spricht von einem Supply-Chain-Angriff auf den offiziellen Verteilkanal. Wie Angreifer Zugriff auf das Konto erhielten, haben weder Cursor noch Anthropic erklärt.[1][3][5]

Die Schadwirkung war begrenzt, aber real. Laut Cursor hätte der Fernzugriff auf den meisten Rechnern nicht funktioniert, da Administratorrechte nötig sind. Heise beschreibt unter Berufung auf Phorion einen Logikfehler unter macOS, der die SSH-Aktivierung meist überspringt. Die Malware legt trotzdem SSH-Keys ab, nistet sich dauerhaft ein und schickt Rechnerinformationen an die Angreifer. The Decoder nennt Hostname, Benutzername, Betriebssystem und öffentliche IP-Adresse.[2][3]

Cursor entfernte die Version, schaltete den Marketplace vorübergehend ab und öffnete ihn wieder. Andere Erweiterungen seien laut Cursor nicht betroffen. Betroffene sollen auf Version 2.1.314 aktualisieren. Phorion zufolge reicht Deinstallieren nicht: Tunnel-Prozesse, Persistenz-Einträge, Dateien wie „~/.config/.smt“ und der Schlüssel „svc-telemetry“ in „~/.ssh/authorized_keys“ müssen entfernt werden.[3][5]

Offen bleibt der Einbruchsweg ins Konto. Ars Technica berichtet zudem, dass Anthropic Kunden bislang nicht öffentlich gewarnt hat. Wer die Erweiterung in dem Zeitfenster installiert hat oder automatisch aktualisieren ließ, muss selbst prüfen, ob die genannten Spuren auf dem Rechner liegen.[1][3]
